Why Top Teams Choose hateum/android-ci-box

Say goodbye to flaky pipeline scripts, slow QEMU arm64 emulation, and broken permissions.

⚡

Native Multi-Arch Silicon

Native compilation on both amd64 and arm64. Build with 100% native silicon speed on Apple Silicon runners, AWS Graviton, and standard Linux servers without slow QEMU translation.

🎯

Zero-Config Dynamic Detection

Ultra-fast static scanner (<50ms) parses build.gradle(.kts) and version catalogs to automatically align target SDKs and Java toolchains without manual pipeline parameters.

☕

Dual-JDK (Java 21 + 17)

Comes with OpenJDK 21 (default) and OpenJDK 17 preinstalled. Instant dynamic toggle via switch-jdk [17|21] in <20ms without restarting the container.

🛡️

Universal Rootless Security

Hardened with universal 777 read/write permissions and sticky-bit /opt. Runs safely under arbitrary UIDs (--user 1000:0 or OpenShift) with zero permission denied errors.

🌐

Dual-Mode Enterprise Network

Works out-of-the-box on the public web. When behind corporate firewalls, automatically imports custom CA certificates into Java truststores and configures HTTP/S proxies & Nexus mirrors.

🚀

Fastlane & Mobile Tooling

Precompiled Ruby 4.0.9 + Fastlane 2.241.2 ready out-of-the-box in /opt/rbenv. Includes Bundletool 1.18.3, Android CLI, and Gradle Managed Devices with SwiftShader headless GPU.

Ready-to-Use CI/CD Configurations

Drop-in pipeline files for your favorite CI platform with built-in caching and best practices.

.github/workflows/android.yml 
name: Android CI

on: [push, pull_request]

jobs:
  build:
    name: Build & Test Android App
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Run Android CI Box Composite Action
        uses: hatem-noureddine/android-ci@v1
        with:
          version: 'latest' # or specific SemVer like '1.4.8'
          run: |
            ci-doctor --summary
            ./gradlew test lintRelease assembleDebug --no-daemon
name: Android CI (Container Job)

on: [push, pull_request]

jobs:
  android-build:
    runs-on: ubuntu-latest
    container:
      image: hateum/android-ci-box:latest
      options: --user 1000:0

    steps:
      - uses: actions/checkout@v4

      - name: Diagnostics & Build
        run: |
          ci-doctor
          ./gradlew test lintRelease assembleRelease --no-daemon

      - name: Deploy via Fastlane
        if: github.ref == 'refs/heads/main'
        env:
          GOOGLE_PLAY_KEY: ${{ secrets.GOOGLE_PLAY_KEY }}
        run: bundle exec fastlane deploy_internal
image: hateum/android-ci-box:latest

variables:
  GRADLE_OPTS: "-Dorg.gradle.daemon=false -Dorg.gradle.parallel=true -Dorg.gradle.caching=true"
  GRADLE_USER_HOME: "$CI_PROJECT_DIR/.gradle"

cache:
  key: "${CI_COMMIT_REF_SLUG}-android"
  paths:
    - .gradle/wrapper/
    - .gradle/caches/

stages: [ test, build ]

unit_tests:
  stage: test
  script:
    - ci-doctor --summary
    - ./gradlew test lintRelease --stacktrace

assemble_release:
  stage: build
  script:
    - ./gradlew assembleRelease
  artifacts:
    paths:
      - app/build/outputs/apk/release/*.apk
      - app/build/outputs/bundle/release/*.aab
pipeline {
    agent {
        docker {
            image 'hateum/android-ci-box:latest'
            args  '--user 1000:0 -v /var/cache/gradle:/home/runner/.gradle'
        }
    }
    stages {
        stage('Diagnostics & Lint') {
            steps {
                sh 'ci-doctor --summary'
                sh './gradlew test lintRelease --no-daemon'
            }
        }
        stage('Assemble Release') {
            steps {
                sh './gradlew assembleRelease --no-daemon'
            }
            post {
                success {
                    archiveArtifacts 'app/build/outputs/**/*.apk, app/build/outputs/**/*.aab'
                }
            }
        }
    }
}

Built-in Diagnostic Suite: ci-doctor

Never waste developer or agent time wondering why a pipeline failed. ci-doctor validates your JDK, Android SDK packages, KVM hardware acceleration, proxies, and enterprise mirror connectivity in milliseconds.

  • ✓ Emits human-readable colored report or machine-readable JSON
  • ✓ Checks OpenJDK 17 and OpenJDK 21 binary readiness
  • ✓ Detects KVM acceleration for Gradle Managed Devices (GMD)
  • ✓ Verifies CA certificates in Java truststore
